# Dokumenty prawne - szablony

To sa szablony robocze do konsultacji z prawnikiem. Nie traktuj ich jako finalnej porady prawnej.

W dokumentach uzywamy pol do uzupelnienia:

- `[NAZWA_FIRMY]`
- `[ADRES_FIRMY]`
- `[NIP]`
- `[EMAIL_KONTAKTOWY]`
- `[DATA_WEJSCIA_W_ZYCIE]`
- `[OKRES_RETENCJI]`
- `[DOSTAWCY_INFRASTRUKTURY]`

Podstawowe dokumenty:

- `regulamin-uslugi.md`
- `polityka-prywatnosci.md`
- `zgody-zdjecia-wideo.md`
- `retencja-danych.md`
- `procedura-usuniecia-danych.md`
- `administrator-danych.md`

Uwagi do konsultacji:

1. Trzeba ustalic role RODO: administrator, procesor, ewentualnie wspoladministrowanie.
2. Trzeba opisac przeplyw danych: para, goscie, zdjecia, wideo, dokumenty, platnosci.
3. Trzeba doprecyzowac retencje danych po weselu i zasady przedluzenia dostepu.
4. Trzeba potwierdzic, czy publikowanie zdjec w galerii wymaga osobnej zgody goscia.
5. Trzeba przygotowac umowe powierzenia dla klientow B2B.
